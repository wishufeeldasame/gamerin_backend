## 5. 멤버십 상품·혜택 정책

### 5-1. 이용권 방식·구매 수단 확정

**확정:** 카카오페이 단건 결제로 30일 이용권을 직접 구매하고 사용자가 직접 재구매한다. 자동 갱신은 제공하지 않는다.

**확정 가격:** 최초 구매·직접 재구매 모두 30일당 4,900원이다. 카카오페이 결제 금액과 멤버십 화면의 표시 가격을 동일하게 사용한다. 멤버십 가격은 서버 상품 정의를 기준으로 검증한다.

정기결제의 SID 저장·청구 스케줄러·자동 갱신 실패 재시도·갱신 해지 API는 후속 범위다. 향후 자동 갱신 상품을 도입할 경우 별도 정책·동의·설계를 진행한다. [참고: 카카오페이 정기결제](https://developers.kakaopay.com/docs/payment/online/subscription)

### 5-2. 확정한 혜택 정책과 구현 방침

**확정:** 금액 혜택은 멤버십 멘토의 정산 수수료 감면이며 일반 10%, 멤버십 5%를 적용한다. 멘티 구매 가격은 유지한다. 멘티 신청 시점에 멘토의 멤버십 상태로 요율을 확정하고 해당 신청에 저장한다.

| 혜택 | 적용 조건 | 만료 시 동작 |
|---|---|---|
| 정산 수수료 감면 | 신청 시점에 **멘토 계정**의 멤버십이 유효 | 이후 새 신청에는 기본 요율, 기존 요율은 보존 |
| 멤버십 배지 | 활성 멤버십 가입 표시; 프로필이 표시되는 모든 사용자 화면의 닉네임 옆에 작은 왕관 아이콘과 `멤버십 회원` 접근성 이름·설명 제공 | 만료 시 배지 제거; 신원·멘토 자격 인증은 별개 |
| 게시물 수정 | 본인 게시물 + 수정 요청 시 유효한 멤버십 + 최초 게시 후 1시간 이내·최대 1회 | 새 수정 요청 제한; 최신 본문 유지 |

**확정 요율 계산 예시:** 10,000 마일리지 멘토링에서 일반 멘토의 수수료는 1,000, 수령액은 9,000 마일리지다. 멤버십 멘토의 수수료는 500, 수령액은 9,500 마일리지다. 할인 대상은 **GamerIN 멘토 정산 수수료**이며 카카오페이 PG 수수료 감면과는 구분한다. 멘티의 구독 여부로 비구독 멘토의 수수료를 낮추지 않는다.

- 신청 시 `fee_rate_bp`에 일반 1000 / 멤버십 500을 저장하고, 정산 시 `fee = floor(applied_mileage × fee_rate_bp / 10000)`를 적용한다. 금액 상한·곱셈 오버플로도 검증한다.
- **확정:** 신청 당시 멤버십이면 정산 전에 만료돼도 해당 건은 5%를 유지한다. 신청 당시 일반 회원이면 진행 중 멤버십을 구매해도 해당 건은 10%를 유지하며, 가입 후 새 신청부터 5%를 적용한다. 수동 완료·자동 정산·관리자 강제 정산 모두 저장한 요율을 사용한다.
- 수동·자동·관리자 강제 정산은 같은 규칙을 사용한다. 잠금·정산 완료 여부·지급·상태·알림의 트랜잭션 경계를 유지한다. 기존 `REQUIRES_NEW` 메서드를 잠긴 외부 트랜잭션에서 그대로 호출하는 식의 통합은 피한다.
- **확정:** 개발 단계이므로 수수료 도입 전 신청에 대한 별도 호환 처리는 구현하지 않는다. 새 기능으로 생성한 신청에서 요율 저장·정산을 검증한다. 이 결정만으로 기존 DB 초기화·데이터 삭제를 실행하지 않는다.
- 멘토링 취소·거절은 기존 전액 마일리지 반환을 유지한다. 충전한 현금의 결제 취소와는 다른 동작이다.

**배지 의미·노출·모양 확정:** 멤버십 가입을 표시하고 이용권 만료 시 제거한다. 사용자 프로필이 표시되는 모든 사용자 화면의 닉네임 옆에 작은 왕관 아이콘을 표시하며 현재 유효한 멤버십 상태로 판정한다. 접근성 이름과 설명은 `멤버십 회원`으로 제공한다. 멤버십 구매에 별도 본인 확인·멘토 자격 심사를 추가하지 않는다.

**구현 방침:** 기존 `verifiedBadge`를 결제 성공 때 영구 true로 바꾸지 않는다. `membershipBadge`처럼 의미를 구분한 응답 필드를 추가하고 현재 이용 기간으로 계산한다. 사용자 정보를 포함하는 응답에 멤버십 배지 상태를 포함하고 프론트에서는 공통 배지 표시를 재사용한다. `멤버십 회원` 설명을 제공하고 사용자 역할·신원 확인·멘토 자격과 구분한다.

**게시물 수정 범위 확정:** 본문 텍스트·해시태그·멘션만 수정할 수 있다. 기존 이미지·영상은 유지하며 미디어 추가·삭제·교체는 허용하지 않는다.

**게시물 수정 시간 확정:** 최초 게시 시점부터 1시간 이내에만 수정할 수 있고 수정 요청 시 멤버십이 유효해야 한다. 수정해도 가능 시간은 연장되지 않는다. 서버에서 최초 게시 시각을 기준으로 검사한다.

**게시물 수정 횟수 확정:** 게시물당 최대 1회 수정할 수 있다. 실제 본문 변경이 저장된 경우에만 횟수를 차감하며 실패하거나 변경 없는 요청은 차감하지 않는다. 이용권 재구매로 수정 횟수를 초기화하지 않는다. 동시 요청으로 1회 제한을 초과하지 않도록 서버에서 검사·저장을 원자적으로 처리한다.

**게시물 수정 이력·표시 확정:** 수정 전 본문은 보관하지 않고 최신 본문만 유지한다. `수정됨` 표시·수정 이력 저장·조회 기능은 구현하지 않는다. 1회 제한에 필요한 수정 횟수 정보만 관리한다. 원 게시물 ID를 유지하며 댓글 수정은 후속 범위다.

- 작성자·멤버십 만료·삭제 상태·시간·횟수를 서버에서 검사한다. 버튼 노출이나 오래된 JWT 정보만으로 허용하지 않는다.
- 기존 텍스트 보안 검사·검열을 재적용하고 해시태그·멘션 관계, 새 멘션 알림의 중복 정책을 처리한다.
- 수정 횟수 검사와 본문 갱신을 원자적으로 처리해 동시 수정을 제어한다. 피드·상세·공유 미리보기에 최신 본문을 반영한다. 수정 전 본문·수정 버전 보관이나 이력 조회 API·화면은 추가하지 않는다.
- 일반 사용자의 삭제 기능은 유지한다. 프로필 수정과 게시물 수정 권한을 혼동하지 않는다.

### 5-3. 이용 기간·재구매·환불

- **확정:** 구매한 이용권은 30일 동안 유효하며 재구매는 사용자가 직접 요청한다.
- **확정:** 기간이 남아 있어도 미리 재구매할 수 있다. 구매 확정마다 `max(구매 확정 시점, 기존 만료일) + 30일`을 적용하며 최초 구매는 구매 확정 시점부터 30일을 부여한다. 남은 기간이 5일이면 재구매 후 35일이 된다.
- 같은 구매 재처리로 두 번 연장하지 않는다. 구매 실패 시 기간을 부여하지 않고 결과 불명은 구매 상태 조회로 확인한다.
- **취소·환불 범위 확정:** 결제 취소 API로 카카오페이 결제 취소와 충전 잔액·멤버십 이용 기간 회수를 구현한다. 사용자 환불 화면·부분 환불·환불 기간 정책은 이번 범위에서 제외한다.
- **결제 취소 허용 조건(확정):**
  - 충전: 현재 지갑 잔액이 해당 충전액 이상이어야 한다. 충전액 전액을 `CHARGE_CANCEL`로 회수한다. 부족하면 거부한다.
  - 이용권: 취소 대상이 사용자의 마지막 `GRANTED` 부여 이력이어야 한다(후속 구매 없음). 해당 구매로 부여한 기간만 회수하며 이전 구매로 남은 기간은 보존한다. 이용 기간 중 게시물 수정·5% 요율 신청 여부는 검사하지 않는다.
- 이미 수정한 게시물·5%로 저장된 신청·완료된 정산은 취소해도 되돌리지 않는다. 부분 환불과 환불 기간 정책은 이번 범위에서 정하지 않는다.
